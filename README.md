# 📊 InsightFlow AI

### Intelligent Sales Analytics & Prediction System

InsightFlow AI is a Data Science and Machine Learning project designed to analyze sales performance, discover business insights, visualize important trends, and predict sales using Machine Learning.

The application provides an interactive analytics dashboard built with Streamlit.

---

## 🚀 Project Overview

Businesses generate large amounts of sales data, but raw data alone does not provide useful decisions.

InsightFlow AI transforms sales data into meaningful information through:

- Sales analytics
- Business KPIs
- Interactive filtering
- Data visualization
- Customer analysis
- Profit analysis
- Machine Learning
- Sales prediction
- Automated business insights

---

## 🎯 Problem Statement

Organizations often have sales data stored in tables without an easy way to analyze it.

The project aims to build an interactive system that can:

1. Analyze sales performance.
2. Identify profitable categories.
3. Compare regional performance.
4. Analyze customer sales.
5. Predict sales using Machine Learning.
6. Present insights through an interactive dashboard.

---

## ✨ Key Features

### 📌 Business Dashboard

- Total Sales
- Total Profit
- Number of Orders
- Average Sales

### 🔎 Interactive Filters

Users can filter the dashboard by:

- Region
- Category

### 📈 Data Visualization

The system provides visualizations for:

- Sales by Category
- Sales by Region
- Profit by Category

### 🏆 Customer Analysis

Identifies customers with the highest sales contribution.

### 🤖 Machine Learning

A Random Forest Regression model is used for sales prediction.

Input features include:

- Quantity
- Discount
- Profit
- Category
- Region

### 💡 Automated Insights

The application automatically identifies:

- Highest sales category
- Highest sales region
- Highest-value customer
